# Diego Piña López — professional website

A responsive, accessible professional website hosted with GitHub Pages at https://diegojplopez.com.

## Pages

- Home: `index.html`
- About: `about.html`
- Selected work: `projects.html`
- Therapy and support: `therapy.html`
- Consulting and training: `consulting.html`
- Media and recognition: `media.html`
- Contact: `contact.html`

The website uses plain HTML, CSS, and JavaScript and requires no build process. Existing local images remain in `assets/Images/`; the current professional portrait is served from Diego’s public Psychology Today profile.
